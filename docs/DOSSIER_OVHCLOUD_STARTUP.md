## 1. Description de la Proposition de Valeur
LexaSafe est une passerelle souveraine de sécurisation des réquisitions judiciaires pour les entreprises françaises et européennes. Face au nouveau Règlement e-Evidence 2026 et aux menaces de fausses réquisitions policières, LexaSafe s'appuie sur le Cloud de confiance d'OVHcloud pour offrir un traitement étanche, sans aucune dépendance aux GAFAM et garanti Zéro Connaissance.

---

## 2. Synergie Stratégique avec OVHcloud
* **SecNumCloud ANSSI :** LexaSafe promeut activement les instances qualifiées SecNumCloud d'OVHcloud comme le standard d'excellence pour la justice numérique en France.
* **Alternative Souveraine :** LexaSafe permet aux grands comptes (Télécom, Banques, Cloud) d'échapper au CLOUD Act américain en centralisant leurs échanges judiciaires sur l'infrastructure OVHcloud.
* **Trafic & Scale :** Chaque entreprise cliente génère un stockage chiffré répliqué sur OVHcloud Object Storage (S3-compatible) avec archivage froid Cold Storage.

---

## 3. Architecture Technique sur OVHcloud
* **Compute :** Instances Public Cloud B2-15 / C2-30 (Processeurs AMD EPYC durcis).
* **Base de données :** Managed Databases for PostgreSQL (Multi-AZ, chiffrement transparent au repos, RLS).
* **Stockage :** High Performance Object Storage pour les réquisitions actives + Cloud Archive pour le séquestre probatoire légal.
* **Sécurité Réseau :** vRack dédié, Anti-DDoS Game/Enterprise, IP Failover françaises.
